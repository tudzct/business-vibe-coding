# Research context

This directory defines the business-rule-oriented, two-phase Vibe Coding method.

- `sources/`: canonical Sheet, prompt template and method reference.
- `business-rules/`: OCL utility definitions and rule guidance.
- `workflow/`: Phase 1 prompt generation and Phase 2 source generation/audit/repair.
- `engineering/`: implementation constraints that support the application but are not experiment dimensions.

The Google Sheet is authoritative for UC, UML and Business Rules. Files under `docs/01-inception/use-cases/` are frozen projections and must not be edited to resolve discrepancies.
