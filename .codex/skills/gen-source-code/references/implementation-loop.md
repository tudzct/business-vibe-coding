# Implementation loop

Database preflight uses the per-run operator-provided input under `docs/00-context/engineering/DATABASE-SCHEMA.md` to verify migration history/head and the live schema fingerprint through deterministic helpers. Apply the [shared operational constitution](../../../../AGENTS.md#shared-operational-constitution) and the owning skill's explicit read boundaries. Preserve actual END/partial evidence and follow the database policy before restarting with new pins. Keep data across cumulative UCs. Rebuild within a run with `--no-deps backend frontend`.

Validate the active run and approved prompt through the required helpers, capture START immediately before the first source mutation, read the [approved prompt](../../../../docs/02-construction/coding-prompts/%3CUC-ID%3E-coding-prompt.md) in full, inspect the current application source and implement the requested change, capture END immediately after generation, and preserve source/hash/evidence. End the response without inspecting or preparing another operation.
