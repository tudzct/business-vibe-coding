# File-driven implementation workflow

Input: one approved `*-business-coding-prompt.md` (Full A-F), matching configuration and activation.

Resolved bundle: checksum-pinned prompt, functional UC/UML/UI/API inputs, technical baseline, source provenance and active run. Full includes the approved BR projection. Audits subsequently use every frozen BR and flow. Follow [Full contract](../../../../docs/00-context/workflow/FULL-CONTRACT.md).

Outputs are source under `finalsource/`, implementation/repair artifacts under `docs/02-construction/implementation/<UC-ID>/`, and canonical run JSON under `docs/05-experiments/<UC-ID>/`.
