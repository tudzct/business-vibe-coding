# File-driven prompt workflow

## Authorized project-content inputs

The complete input inventory and access boundaries are defined once in [Primary Inputs](../SKILL.md#primary-inputs). This reference authorizes no additional project-content source. Authoring instructions belong to `templates/construction/coding-prompt.template.md`.

## Outputs

- `docs/02-construction/coding-prompts/<UC-ID>-coding-prompt.md` as the Draft;
- Live prompt timing evidence appended via deterministic timestamp capture.

Provenance and checksums are preserved in operation-owned telemetry and control-plane artifacts without relying on chat history.
